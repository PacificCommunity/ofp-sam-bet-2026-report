# Revision 1 replacement figures

This directory contains the replacement and additional figures used by the
revised report. The original report figures remain unchanged in `figures/` so
that the previous and revised graphics are both retained.

Unless noted below, the files were copied from the BET 2026 diagnostic report
at commit `a2fafad4ec61c85178aaa1313cbe86696bd395ac`:

- `diagnostic-report-output/figures/` for the diagnostic, likelihood-profile,
  ASPM and Hessian figures; and
- `diagnostic-report-output/mfclshiny/figures/` for the spatial structure,
  model-fit and population-dynamics figures.

`projection-stock-trajectories.png` was decoded without resampling from the
self-contained figure embedded in
`/home/kyuhank/Downloads/bet-2026-ensemble-report.html`, section
`projection-stock-trajectories` (All-region projection trajectories).

The report source, rather than this directory, records the final figure order,
cross-reference identifiers and publication captions.

`appendix-mfcl-movement.png`, `appendix-seapodym-movement.png` and
`appendix-no-tag-model-comparison.png` were exported at 300 dpi from
`sources/Appendix for bigeye.docx`. The first two retain the Word document's
5 x 5 donor--recipient layout; the second matrix is joined from the two source
pages without changing the underlying content.
